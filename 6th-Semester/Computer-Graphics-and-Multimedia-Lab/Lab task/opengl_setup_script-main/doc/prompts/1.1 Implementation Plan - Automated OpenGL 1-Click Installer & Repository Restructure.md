## Proposed Changes

### Root Scripts & Documentation

#### [NEW] [install_opengl_admin.bat](file:///c:/Users/.../Documents/GitHub/[personal]/opengl_setup_script/install_opengl_admin.bat)
- Interactive, self-elevating Administrator Windows batch script.
- Auto-detects existing MSYS2 installation (`C:\msys64`). If missing, runs `msys2-x86_64-20260611.exe` in unattended/quiet mode.
- Executes `pacman -S --noconfirm base-devel gcc` to install `g++.exe`, `gcc.exe`, and `make.exe`.
- Permanently updates System/User `PATH` environment variable with `C:\msys64\usr\bin` and `C:\msys64\mingw64\bin`.
- Pre-checks GLFW runtime DLL (`glfw3.dll`) and header dependencies.
- Offers interactive compilation test (`make win`) on `Graphics_Lab_Install_AG/Lab0`.

#### [NEW] [uninstall_opengl_admin.bat](file:///c:/Users/.../Documents/GitHub/[personal]/opengl_setup_script/uninstall_opengl_admin.bat)
- Self-elevating cleanup script.
- Optionally removes `C:\msys64\usr\bin` from System `PATH`.
- Cleans up generated binaries (`.exe`) inside `build/` folders across sample projects.
