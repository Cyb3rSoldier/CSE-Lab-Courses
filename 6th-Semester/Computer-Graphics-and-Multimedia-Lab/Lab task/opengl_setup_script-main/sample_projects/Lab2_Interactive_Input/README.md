# Lab 2: Interactive GLFW Keyboard Input Controls

This sample project demonstrates interactive user input handling using GLFW callbacks (`glfwGetKey`, `GLFW_KEY_ESCAPE`, `GLFW_KEY_R`, `GLFW_KEY_G`, `GLFW_KEY_B`, `GLFW_KEY_SPACE`).

## Controls
- **`[ESC]`**: Exit window
- **`[R]`**: Increase Red background channel
- **`[G]`**: Increase Green background channel
- **`[B]`**: Increase Blue background channel
- **`[SPACE]`**: Reset background color

## How to Build and Run

### Windows (MSYS2 / MinGW-w64)
```bash
make win
```

### Linux
```bash
make linux
```
