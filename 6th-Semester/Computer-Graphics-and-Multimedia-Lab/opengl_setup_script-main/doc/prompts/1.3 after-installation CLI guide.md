### Why the links weren't clickable previously & how it was fixed:
1. **Isolated Link Lines**: Terminals (such as VS Code Terminal and Windows Terminal) rely on URL regex parsers. Placing URLs directly after inline text labels on the same line (e.g. `echo - Sample Projects: https://...`) often interferes with link detection. Each link is now placed on its own line.
2. **`file:///` URI Scheme with Bracket Encoding (`%5B` / `%5D`)**: Raw Windows file paths containing square brackets (such as `...\[personal]\...`) break terminal path link detectors because `[` and `]` are reserved delimiter characters. The script now dynamically converts the local path into a properly formatted `file:///` URI with percent-encoded brackets (`file:///.../%5Bpersonal%5D/...`) alongside the local Windows folder path.
